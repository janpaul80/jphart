## Troubleshooting

### Widget Still Not Showing?

1. **Clear browser cache** (Ctrl+Shift+Delete)
2. **Hard refresh** the page (Ctrl+Shift+R)
3. **Check Watermelon dashboard:**
   - Verify agent is "Active"
   - Check widget is published
   - Confirm `jphart.dev` is in allowed domains

### Widget Shows But Agent Doesn't Respond?

1. Check agent status in dashboard
2. Verify model (gpt-5.1) is selected
3. Ensure personality and guardrails are saved
4. Try recreating the agent
