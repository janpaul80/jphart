## If You Want to Upload Files

### Supported File Types:
- `.docx` (Word documents)
- `.txt` (Text files)
- `.pdf` (PDF documents)

### How to Upload:
1. **Drag and drop** files into the box, OR
2. **Click "browse"** to select files from your computer
3. Files will be uploaded and scanned
4. Agent will learn from the content
